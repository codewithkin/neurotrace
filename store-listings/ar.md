# ar (العربية)

## App name
```
NeuroTrace: سجل أعراض ADHD
```

## Short description
```
فرز ذاتي خاص لـ ADHD وسجل يومي للتركيز، مجانًا وبخصوصية تامة.
```

## Full description
```
NeuroTrace هو فاحص ذاتي خاص لاضطراب فرط الحركة وتشتت الانتباه يعمل محليًا بالكامل، مع سجل يومي للأعراض، مصمم للبالغين الذين يستكشفون أو يديرون تحديات التركيز والخلل الوظيفي التنفيذي وسمات الانتباه.

اعتمادًا على مقياس التقارير الذاتية الرسمي لمنظمة الصحة العالمية (WHO) للبالغين (ASRS v1.1)، يساعدك NeuroTrace على تنظيم أعراضك في ملخص منظم قابل للطباعة يمكنك مشاركته مع طبيبك أو معالجك — مجانًا تمامًا، بدون حساب وبدون سحابة.

الميزات الرئيسية

• الفاحص الرسمي ASRS v1.1 — أكمل التقييم الذتي المكوّن من 18 سؤالًا في نحو أربع دقائق، بما في ذلك الفرز الأساسي للجزء أ والقياس الكامل للشدة.
• تقرير PDF جاهز للطبيب — أنشئ ملخصًا منظمًا يضم مصفوفة إجاباتك وتفصيل المقاييس الفرعية والإجابات المُعلَّمة. احفظه في ملفاتك أو شاركه عبر البريد أو واتساب، أو اطبعه لزيارتك.
• تسجيل يومي في 10 ثوانٍ — سجّل مستوى التركيز وضباب الدماغ والاحتكاك التنفيذي والمزاج وتناول الدواء بمؤشرات بسيطة، مع عداد متتابع يرسّخ العادة.
• السجل والاتجاهات — قارن الفحوصات السابقة جنبًا إلى جنب، وتابع تطور درجاتك، واحصل على مؤشرات حالة: مستقر أو متحسن أو مرتفع.
• تذكيرات إعادة التقييم — إشعارات محلية اختيارية تذكّرك بإعادة الفحص كل 30 يومًا.
• دعم متعدد اللغات — مترجم بالكامل إلى الإنجليزية والإسبانية والألمانية والفرنسية والبرتغالية واليابانية والإيطالية والهولندية والبولندية والعربية.
• يعمل دون اتصال — أجرِ الفحص في أي مكان. يُحفظ تقدمك تلقائيًا على جهازك.

الخصوصية أولًا

إجاباتك ودرجاتك وتسجيلاتك اليومية تُخزَّن على جهازك فقط. لا حاجة لحساب. لا يتم رفع أي شيء — لا خادم ولا قاعدة بيانات سحابية ولا تتبع للبيانات الصحية. واحذف كل شيء متى شئت من الإعدادات.

إخلاء مسؤولية

NeuroTrace قائمة تحقق تعليمية للتقرير الذاتي مبنية على إطار WHO ASRS v1.1. وهي ليست اختبارًا تشخيصيًا طبيًا ولا تقييمًا إكلينيكيًا ولا نصيحة صحية. نتيجة الفرز الإيجابية ليست تشخيصًا — استشر دائمًا مختصًا طبيًا مؤهلًا للتشخيص والعلاج الإكلينيكي.
```
