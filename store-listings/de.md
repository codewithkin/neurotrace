# de-DE

## App name
```
NeuroTrace: ADHS-Symptomlog
```

## Short description
```
Privates ADHS-Screening und täglicher Fokuslog. Kostenlos und lokal.
```

## Full description
```
NeuroTrace ist ein privates, lokal arbeitendes ADHS-Screening und ein tägliches Symptomtagebuch für Erwachsene, die Konzentrationsherausforderungen, exekutive Dysfunktion und Aufmerksamkeitsmerkmale erkunden oder managen.

Basierend auf der offiziellen Selbstauskunftsskala der Weltgesundheitsorganisation (WHO) für Erwachsene mit ADHS (ASRS v1.1) hilft Ihnen NeuroTrace, Ihre Symptome in einer strukturierten, druckbaren Zusammenfassung zu ordnen, die Sie Ihrem Arzt oder Therapeuten mitgeben können — völlig kostenlos, ohne Konto und ohne Cloud.

WICHTIGSTE FUNKTIONEN

• Offizielles ASRS-v1.1-Screening — absolvieren Sie die 18 Fragen der Selbsteinschätzung in rund vier Minuten, inklusive Kernscreening Teil A und vollständiger Schweregradbewertung.
• Arztfertiger PDF-Bericht — erstellen Sie eine strukturierte Zusammenfassung mit Antwortmatrix, Subskala-Aufschlüsselung und markierten Antworten. Speichern, per E-Mail oder WhatsApp teilen oder für den Termin ausdrucken.
• 10-Sekunden-Tagescheck — erfassen Sie Fokuslevel, Brain Fog, exekutive Reibung, Stimmung und Medikamenteneinnahme mit einfachen Reglern, dazu ein Streak-Zähler für die Gewohnheit.
• Verlauf & Trends — vergleichen Sie frühere Screenings nebeneinander, beobachten Sie Ihre Wertetrends und erhalten Sie Statusanzeigen: stabil, verbessernd oder erhöht.
• Erinnerungen zur Neubewertung — optionale lokale Benachrichtigungen erinnern alle 30 Tage an eine erneute Einschätzung.
• Mehrsprachigkeit — vollständig übersetzt in Englisch, Spanisch, Deutsch, Französisch, Portugiesisch, Japanisch, Italienisch, Niederländisch, Polnisch und Arabisch.
• Funktioniert offline — machen Sie das Screening überall. Ihr Fortschritt wird automatisch auf dem Gerät gespeichert.

DATENSCHUTZ ZUERST

Ihre Antworten, Werte und Check-ins werden ausschließlich auf diesem Gerät gespeichert. Kein Konto nötig. Nichts wird hochgeladen — kein Server, keine Cloud-Datenbank, kein Tracking von Gesundheitsdaten. Alles jederzeit in den Einstellungen löschbar.

HAFTUNGSHINWEIS

NeuroTrace ist eine pädagogische Selbsteinschätzungs-Checkliste auf Basis des WHO-Rahmens ASRS v1.1. Es ist kein medizinischer Diagnostiktest, keine klinische Untersuchung und kein Gesundheitsrat. Ein positives Screening ist keine Diagnose — konsultieren Sie immer eine qualifizierte medizinische Fachkraft für Diagnose und Behandlung.
```
