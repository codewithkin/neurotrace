NeuroTrace：ADHD症状ログ

## Short description
```
プライベートなADHDセルフスクリーニングと毎日のコンディション記録。
```

## Full description
```
NeuroTraceは、集中力の課題、実行機能の不全、注意の特性を探ったり管理したりする大人のための、プライベートでローカル完結型のADHDセルフスクリーナー兼毎日の症状ログです。

世界保健機関（WHO）公式の成人ADHD自己報告尺度（ASRS v1.1）に基づき、症状を構造化された印刷可能なサマリーに整理し、医師やセラピストに渡すことができます。アカウント登録もクラウドも不要、完全無料です。

主な機能

• 公式ASRS v1.1スクリーニング — 18問の自己報告評価を約4分で完了。パートAのコアスクリーニングと完全な重症度スコアリングを含みます。
• 医師向けPDFレポート — 回答マトリクス、サブスケールの内訳、フラグ付き回答を含む構造化サマリーを生成。ファイルに保存、メールやWhatsAppで共有、診察用に印刷できます。
• 10秒のデイリーチェックイン — 集中レベル、脳の霧、実行機能の摩擦、気分、服薬を簡単なスライダーで記録。連続記録カウンターが習慣化を支援します。
• 履歴と傾向 — 過去のスクリーニングを並べて比較し、スコアの推移を追跡。安定・改善・上昇のステータス表示も。
• 再評価リマインダー — 任意のローカル通知が30日ごとの再スクリーニングをお知らせします。
• 多言語対応 — 英語・スペイン語・ドイツ語・フランス語・ポルトガル語・日本語・イタリア語・オランダ語・ポーランド語・アラビア語に完全対応。
• オフライン動作 — どこでもスクリーニング可能。進行状況は自動的に端末内に保存されます。

プライバシー第一

回答・スコア・チェックインは端末内にのみ保存されます。アカウント不要。アップロードされるものは一切ありません — サーバーなし、クラウドデータベースなし、健康データの追跡なし。すべて設定からいつでも削除できます。

免責事項

NeuroTraceはWHO ASRS v1.1フレームワークに基づく教育目的の自己報告チェックリストです。医学的診断テスト、臨床評価、健康アドバイスではありません。陽性スクリーニングは診断ではありません — 臨床的な診断と治療については、必ず資格を持つ医療専門家に相談してください。
```
